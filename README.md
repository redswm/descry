# descry
<h2>Список возможностей</h2>

<ul>
  <li>Numpad
    <ul>
      <li>Numpad- Открывает Уведомления</li>
      <li>Numpad+ Открывает Лиды</li>
      <li>Numpad* Читает вслух верхнее уведомление в Уведомлениях | Последнее сообщение в мессенджере | Заголовок страницы</li>     
      <li>Numpad* Если вызвано на странице сделки, также копирует email в буфер</li>
       <li>Numpad** (Дважды быстро) Нажимает кнопку последнего разговора</li>
      <li>~ (ЗАГОТОВКА) - Закрывает лид как "Некачественный" после ожидания 5 секунд</li>
<li> ↑ / ↓ Предыдущее/Следующее сообщение</li>
     
    </ul>
  </li>  
  <li>CSS
    <ul>
      <li>Вместо исчезающей кнопки закрытия уведомлений увеличинная кнопка "XXX"</li>      
    </ul>
  </li>
  <li>Функции

    </ul>
