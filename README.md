# descry

<h2>Установка</h2>

1. Установить и активировать плагин <a href="[https://chromewebstore.google.com/detail/chrome-extension-source-v/jifpbeccnghkjeaalbbjmodiffmgedin](https://chromewebstore.google.com/detail/user-javascript-and-css/nbhcbdghjpllgmfilhnhkllmkecfmpld)">User JavaScript and CSS</a>
2. Находясь на сайте bitrix24.ru нажать на кнопку плагина
3. Добавить сайт Bitrix
4. Слева - JS, Справа - CSS, Внизу выбрать кнопку - Все фреймы

<h2>Список возможностей</h2>

<ul>
  <li>numpad.js
    <ul>
      <li>Numpad- Открывает Уведомления</li>
      <li>Numpad+ Открывает Лиды</li>
      <li>Numpad* Читает вслух верхнее уведомление в Уведомлениях | Последнее сообщение в мессенджере | Заголовок страницы</li>     
      <li>Numpad* Если вызвано на странице сделки, также копирует email в буфер</li>
       <li>Numpad** (Дважды быстро) Нажимает кнопку последнего разговора</li>
      <li>~ (ё) Закрывает лид как "Некачественный" (на странице лида)</li>
<li> ↑ / ↓ Предыдущее/Следующее сообщение (на странице переписки)</li>    
      <li> &rarr; Включить 2-ю стадию лида</li> 
    </ul>
  </li>  
  <li>CSS
    <ul>
      <li>Вместо исчезающей кнопки закрытия уведомлений увеличинная кнопка "XXX"</li>      
    </ul>
  </li>
  <li>Функции
    <ul>
      <li>flashScreen() запускает мерцание экрана</li>      
       <li>playSound() запускает короткий звуковой сигнал</li>      
    </ul>
  </li>
</ul>
